# 色彩修復室

記憶を頼りに、失われた色を取り戻す。12点のオリジナル絵画を舞台にした、時間制限のない色彩記憶・調色パズルです。HTML / CSS / JavaScriptのみで動作し、外部API・ログイン・ビルドは不要です。

追加作品: 「風を待つ帆」（やさしい・6色）、「実りの静物」（ふつう・6色）。各作品のすべての色を修復対象として選べます。

## 遊び方

1. 作品を選び、修復する領域を選択します。白い点線の部分の色を観察してください。
2. 「調色する」で原画を隠し、色相・彩度・明度を調整します。
3. 「原画を確認する」で何度でも観察に戻れます。調色状態は維持されます。
4. 「修復を完了する」で、1色のみを置き換えた絵画と採点結果を表示します。
5. 「美術館に展示する」でコレクションに追加します。全プレイは記録にも残ります。

Tabで移動、Enter / Spaceでボタン操作、矢印キーでスライダーを調整できます。確認回数は初回観察を除く再確認回数です。調色時間は調色画面の滞在時間で、観察時間は含みません。これらによる減点はありません。

## ローカル起動

```sh
cd /workspace
python -m http.server 8000 --bind 127.0.0.1
```

ローカルブラウザでは `http://127.0.0.1:8000/color-restoration/` を開きます。ES ModulesとService Workerのため、HTMLファイルを直接開かずHTTPで配信してください。PWAはlocalhostまたはHTTPSで動作します。

## GitHub Pages公開

1. このリポジトリのファイルを `main` にコミットしてGitHubへpushします。
2. GitHubの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選択します。
3. ブランチを **main**、フォルダを **/ (root)** にして保存します。
4. デプロイ完了後、`https://ning2yin1.github.io/color-restoration/` で遊べます。

相対パス・相対PWAスコープのため、プロジェクトのサブディレクトリに対応しています。`.nojekyll` も配置済みです。初回オンライン読み込み後は基本ゲーム機能がオフラインで使えます。インストールは対応ブラウザのメニューから行い、iPhoneではSafariの共有メニューの「ホーム画面に追加」を使用します。

Service Workerはネットワーク優先で、通信失敗時に保存済みファイルを返します。アセット構成を変更するリリースでは `sw.js` の `CACHE` バージョンを上げ、`FILES` も更新してください。初回オフラインアクセスはできません。

## ファイル

- `index.html` / `style.css` / `script.js`: 画面、レスポンシブUI、ゲームと保存処理
- `art.js`: 12作品のSVG構図、パレット、領域データ
- `outlines.js`: 修復対象パーツの合成シルエットから生成した外周パス
- `color.js`: HSL変換・OKLab変換・採点
- `audio.js`: Web Audio効果音、任意BGM管理
- `manifest.json` / `sw.js` / `assets/icon*`: PWA、オフライン、アイコン
- `tests/`: 数学・作品データのテストとブラウザ統合テスト

採点式は `clamp(100 - OKLab距離 × 250, 0, 100)`。`color.js` の `SCORE_SENSITIVITY` で感度を変更できます。完全一致は100点、小数点第1位まで表示します。ゲーム記録と音量設定はlocalStorageに保存し、同じ作品の複数プレイを保持します。プライベートブラウズや容量不足で保存できない場合は通知します。

## BGM

添付音源 `assets/audio/Café Piano.mp3` を収録しています。初回のボタン操作後にループ再生し、画面を切り替えても再生位置を維持します。新規利用者はBGM ON / 音量20%が初期値です。既存利用者の保存済みON/OFF・音量はそのまま維持します。設定画面でBGMと効果音を独立して調整できます。効果音発生時はBGMを滑らかに15%だけ下げます。音源を読み込めなくてもゲームは継続できます。

ファイル名の空白・アクセント文字は `new URL()` で正しく処理します。MP3をService Workerのオフラインキャッシュに収録し、Safari等の音声プレイヤーが必要とするバイト範囲リクエストにも対応しています。MP3の取得に失敗してもゲーム本体のキャッシュ登録は完了します。

音源を差し替える場合は同じファイルを置き換え、`sw.js` のキャッシュバージョンを上げてください。ファイル名も変える場合は `audio.js` と `sw.js` のパスを合わせて変更します。ブラウザ・OSによっては最初のユーザー操作後にも再生が制限される場合があるため、設定でBGMをONにし直してください。

## 1画面の修復室

原画確認と調色は `100dvh` とセーフエリアを使った画面高のGridレイアウトです。絵画は縦横比を保って利用可能な領域へ収め、スライダーは44pxのタッチ操作領域を確保しています。画面外のコンテンツを `overflow: hidden` で隠していません。原画と調合色は別画面のままです。

## 検証

```sh
cd /workspace/color-restoration
node --test tests/color.test.mjs
# PlaywrightとChromiumがインストールされた開発環境で、上記HTTPサーバー起動中に実行
node tests/browser.cjs
node tests/viewport-audio.cjs
node tests/outlines.cjs
```

ブラウザテストはPlaywrightパッケージが必要です（アプリ自体には不要）。既定では `/usr/bin/chromium` を使い、別の場所にある場合は `CHROMIUM_PATH` を指定できます。Node.js 22以上を推奨します。

確認済み: OKLab基準値、採点範囲、12作品すべての対象領域だけの置換、Chromiumでのプレイと再確認時の色保持、展示、リロード後の記録復元、横並び比較、375/390/768/1440pxの画面幅、主要調色ボタンの画面内表示、サブディレクトリでのオフライン再読み込みとプレイ。

追加確認済み: Chromiumで1920×1080、1366×768、390×844、375×667と375×567の原画確認・調色両画面のスクロールなし／全要素表示、タッチによるスライダー操作、BGMの操作後再生・ループ・画面切替時の継続・独立音量設定保存、オフラインMP3再生と206バイト範囲応答、音源404時のプレイ。

未確認: iPhone Safari / Android実機、実機でのPWAインストール。公開前に実機で音量・タッチ操作・インストールを確認してください。

## 修復対象の点線輪郭

同じ修復対象の塗り面・線を4倍解像度で合成し、透明部分との境界を追跡してSVGの輪郭パスを生成しています。重なるパーツの内部境界は合成時に消え、離れた領域や穴はそれぞれの境界を保持します。輪郭の簡略化誤差は最大0.125 SVG単位です。ゲームでは生成済みのパスを直接表示するため、実行時のCanvas処理や外部ライブラリは不要です。点線は白・幅2.5・間隔6/5を維持し、角の継ぎ目を丸くしています。

作品のパーツ・修復対象を変更／追加したら、PlaywrightとChromiumがある開発環境で次を実行して生成ファイルを更新してください。

```sh
node tools/generate-outlines.cjs
node --test tests/color.test.mjs
node tests/outlines.cjs
```

`node tools/generate-outlines.cjs --check` で生成結果の一致も確認できます。作品データのハッシュをテストするため、輪郭の更新漏れは検出されます。輪郭テストは全12作品・64対象について、内部に不要な線が出ていないことを画素で検証し、旧方式の黒猫では実際に不合格になることも確認します。PC・スマホの画面サイズで全対象を表示して検証します。iPhone Safari実機の検証は別途必要です。
